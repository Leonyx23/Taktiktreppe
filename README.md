# Taktiktreppe

Schach-Trainer als Web-App: 11 Eröffnungskurse (Lernen, Wiederholen mit Wiederholungs-Rhythmus, Drill, Zeit, Puzzles, Arena), Taktik-Puzzles in 7 Elo-Stufen und Trainingspartien gegen 7 Bots.

Die App ist passwortgeschützt: `index.html` enthält sie nur verschlüsselt (AES-GCM, Schlüssel per PBKDF2 aus dem Passwort).
