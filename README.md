# Taktiktreppe

Schach-Trainer als Web-App: Taktik-Puzzles in 7 Elo-Stufen, Eröffnungen zum Ansehen und Üben, Fallen-Szenarien aus der Eröffnung und Trainingspartien gegen 7 Bots.

Die App ist passwortgeschützt: `index.html` enthält sie nur verschlüsselt (AES-GCM, Schlüssel per PBKDF2 aus dem Passwort).
